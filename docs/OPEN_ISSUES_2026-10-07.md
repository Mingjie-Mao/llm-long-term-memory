# 问题清单与分层诊断（2026-10-07）

所有数字来自已暴露的开发集（train150、dev100、heldout100）上的零调用诊断或已完成实验，
**都不是未见终测成绩**。dev100 的逐题错误已在 2026-10-07 读过，此后只作开发证据。
诊断顺序按 AGENTS.md 的首失层：原始对话 → 抽取 → 时间键 → 去重 → 生命周期 → 存储 → 检索
→ 原文回退 → 回答。

## 一、错题在哪一层（dev100，v1 三次运行，26 道错题）

| 层 | 题数 | 换更强回答模型能否解决 | 依据 |
|---|---:|---|---|
| 回答：时间推理 | 9 | 部分 | [错题分类](../results/analysis/error-taxonomy-dev100-v18-v1.md) |
| 回答：跨会话计数／求和（证据齐全） | 5 | 较能 | 同上 |
| 回答：读取／比较 | 2 | 能 | 同上 |
| 回答：应拒答而作答 | 2 | 一般 | 同上 |
| **记忆层：知识更新**（回答取了旧值） | 4 | **不能根治** | 见第二节 |
| **检索：证据不全** | 3 | **不能** | 见第三节 |
| 评分可商榷 | 约 1–2（计入上面） | 不能 | 见第六节 |

外部参照：LongMemEval 论文中 GPT-4o 只读标准证据也只有 87.0%，加 Chain-of-Note 92.4%；
Hindsight 同一系统换 20B／120B／Gemini-3 回答模型为 83.6／89.0／91.4%。换模型约值
5–10 个点，但证据缺失和记忆状态错误不会因此消失。

## 二、知识更新：生命周期几乎不触发（新发现，零调用）

4 道知识更新错题全部在记忆层出错：

| 题 | 记忆层状态 | 层 |
|---|---|---|
| `59524333` 健身时间 | 用户说的"通常 6:00 pm"未被抽取；存下的是**助手建议**"7:00 pm 设提醒"，以事实形式出现 | 抽取 |
| `945e3d21` 瑜伽频率 | 改为每周三次未被抽取，只有"每周两次"且为当前 | 抽取 |
| `c4ea545c` 健身频率 | 新旧两条（`gym_schedule`、`exercise_frequency`）都为当前，未发生替代 | 时间键／生命周期 |
| `a1eacc2a` 短篇数量 | "四篇"与"七篇"（`writing_output`、`short_stories_completed`）都为当前 | 时间键／生命周期 |

根因：抽取器自由命名谓词，替代只在同一（主语，谓词）键内由规则判断。三个库中被标为
"替代此前事实"的记忆，**85–88% 在同一键下没有任何更早事实**（train150 777/902，
dev100 528/618，heldout100 546/622）；每库真正被标为已替代的记忆只有 42–76 条，
谓词种类 3,502–5,054 个。做法参照：Mem0 按相似记忆而非键名判定增改删；Zep 在实体边上
标 `invalid_at`。下一步：把孤立的"替代"事实与同主语、语义最近的旧事实链接，先离线在知识
更新题上测"当前记忆是否只剩新值"，再决定是否替代；需要事前注册。

## 四、偏好（零调用）

三套题 21 道偏好题：9 道有某条记忆落在金标轮上，但都存成普通事实（如"用户有 iPhone 13
Pro""用户做菜用罗勒和薄荷"），没有偏好类型；12 道完全没有抽到。基准上靠原文检索可答，
产品个性化要靠抽取改进（需抽取额度）。

## 五、记忆出处错位（零调用）

dev100 可核验 4,272 条中 v2 定位错 161 条（3.8%），主要是"助手推荐了 A、B、C"这类
清单记忆被挂到后来只提到其中一两项的轮次（同为助手 97 条、相邻轮 42 条）。候选修法：
清单类记忆取包含最多条目的轮次，平局取最早。对基准影响小，暂未实施。
