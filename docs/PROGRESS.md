# 项目进展

已完成的工作、存在的问题和接下来的计划。逐项实验的预注册、数据和判定见
[实验索引](../research/EXPERIMENT_INDEX.md)。除冻结 v2 终测外，下面的数字都来自已暴露的
开发集，是开发证据，不是未见终测成绩。

## 已完成

**记忆系统**：两阶段事实抽取、去重、时间状态管理（新增／替换／终止，`as_of()` 查历史）、
来源追踪、原文按需恢复、多用户隔离，提供 REST 和 MCP 接口。

**冻结 v2 终测**（LongMemEval-S 100 题）：LLTM v2 72%，naive RAG 65%，Full Context 86%；
回答＋评分 token 比 naive RAG 少约 88%。

**原文为主（v1）**：记忆负责事实状态，再按问题从原始对话里检索 4,000 token 原话一起给回答模型。
heldout100 上 83/100（对照 69），train150 上 127/150（对照 98）。之后的改进都以它为对照。

**回答侧改进**：相对日期按对话日期换算并标注；不同对话说法冲突时以最近一次为准；计数题和
涉及日期、时长、先后的问题先逐条列出证据再作答。小探针上，时间推理错题 0→5，计数／知识更新
错题 2→5。

**检索侧改进**：同样的预算下优先装用户自己的话；问题里有"上周六""一周前"时按时间窗口检索。
标准原话全部进入上下文的比例：train150 78.1% → 90.4%，dev100 83.5% → 92.8%。

**负结果**：分页通读全部历史并逐条核验引用的方案（grounded v18）在 dev100 上比 v1 平均少答对
3.3 题，调用量是 v1 的 3.6 倍，已放弃。

**进行中**：v1、t3（回答侧改进）、t4（回答侧＋检索侧改进）在 heldout100 上各跑 3 次的正式比较
（[预注册](../results/prereg-raw-primary-t3-t4-heldout100-v1.md)）。

## 存在的问题

| 问题 | 说明 | 换更强的回答模型能否解决 |
|---|---|---|
| 新旧值替换几乎不生效 | 抽取器给同一类事实起不同的谓词名，替换只在同名下判断；被标为"替代"的事实 85–88% 找不到旧值 | 不能 |
| 部分证据检索不到 | 跨多次对话的计数题、只靠时间定位的问题；抽到了但语义上离问题远的画像事实（如年龄） | 不能 |
| 回答读错、算错、选错 | 证据已在上下文里仍答错，占 dev100 错题的大多数 | 部分 |
| 偏好没被抽成偏好记忆 | 21 道偏好题中 12 道什么都没抽到 | 部分（换抽取模型） |
| 记忆出处偶尔指错原话 | 约 3.8%，多为助手推荐清单 | 不能 |
| 评测受限 | LongMemEval-S 已全部用过，没有未见题；单次运行噪声约 7 题；少数题评分有争议 | 不能 |

## 接下来

1. 完成 t3/t4 正式比较，看回答侧、检索侧各自带来多少提升。
2. 修复新旧值替换：按语义相似度找被替代的旧事实，而不只看谓词名。
3. 常驻一个小的用户画像（年龄、职业、住址等），不依赖问题检索。
4. 在最好的方案上试一次更强的回答模型，量出换模型还能提升多少。
5. 用 BEAM 做一次未见集终测（9 月已做好接入，需要额度或付费层）。
6. 改进偏好抽取；评分改为多模型投票加人工抽查。
