    BUILT FOR LONG-TERM MEMORY

    Keep facts, time and provenance together.

    Queryable historical state

    Separate session dates from event dates and preserve validity intervals, so past fact states remain queryable after updates.

    Inspectable answer evidence

    Inspect selected memories, source turns in the first prompt and conditional recovery. Provenance helps diagnose errors; it does not guarantee a correct answer.

    User isolation + tool access

    Memory and source reads stay within the user namespace. Integrate through REST, MCP, Python or CLI; the caller manages current conversation context.
