## Smallest changes, unchanged models and pool

- For a quoted string absent from its declared source, accept only one narrow
  literal escape normalization (backslash-quote/apostrophe/newline) whose result
  actually occurs in THAT declared body. No cross-source text matching. Preserve
  the original provider response and transformation in audit.
- For a selected duration memory lacking its own date, use its unique raw turn
  with exact session+turn and same role only if the selected memory quote is real,
  its subject-stripped event phrase occurs in that raw body, and that raw body has
  a unique independently resolved date. Never use a bare conversation timestamp.
  Recompute time from actual raw words; clear model numeric/date value and unit
  fields for duration, which the code does not need or trust.
- Valid observations already constitute a source review; add their known ids to
  reviewed_sources without overriding exclusions/uncertainty or unknown sources.
- Remove a redundant QUESTION_DATE only for an explicit historical "when" or
  "between" question with two grounded actual endpoints. Validate the resulting
  records with the same calculator. Ongoing/as-of questions retain question-date
  endpoints; missing actual historical endpoints still refuse.
- Location questions needing context put relevant same-session USER neighbors
  first in the verification view. Keep all bodies once and preserve provenance;
  one coherent context may support a labeled likely-place inference, not certainty.
- Count instructions require event identities based on participants/objects and
  supported event time, not numbered rows, kinship aliases alone, mention dates,
  or merely helping to plan an event. Unnamed identity/time ambiguity remains
  explicit; do not manufacture an exact total to match the reference.
