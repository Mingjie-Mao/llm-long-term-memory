# 一次性执行链

2026-10-10 Australia/Sydney，用户明确要求“原 test100 完整继续跑完”。
本修订只安排依赖关系，不改变预注册的题集、模型、回答、评分、预算或 gate。

`tools/run_original_test100_after_dev.py --execute` 以单次进程等待当前已获授权的
dev100 验收进程。最多等12小时，检查间隔30秒。仅当父进度为 COMPLETE、pass 为 typed True，
且完整 gate 的 pass 为 typed True、inventory SHA 绑定一致时，启动原注册 test100 命令一次。
真实调用仍由原工具生成完整冻结清单后执行；缺失／失败前置门不绕过。

若父进程已停止、日配额等待或前置失败，执行链保存状态并停止；不会重新启动父进程，
不追加恢复预算。test100 自身因配额、错误或恢复耗尽退出时，执行链也退出，不自动重启。
这是单次评测依赖执行，不创建定时自动化、cron 或周期任务；不自动提交、推送或发布数字。
用户仍保留完成后更新数字、一条 commit 和 push 的原授权。

等待前绑定本工具、相关测试、原注册执行工具、preflight、resolution、父执行清单和本修订
的 SHA；等待中拒绝源变更。独立锁禁止同时启动两条执行链。模型调用成本仍按原注册计，
执行链检查文件不调用模型，不检查逐题正确率。
