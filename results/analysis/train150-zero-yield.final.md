# train150 零产出最终分析

> 这份报告只给出证据能支持的结论。`没有生成记忆`不自动等于模型出错。

## 总览

| 项目 | 数量 |
|---|---:|
| 全部会话 | 7,180 |
| 全部零产出会话 | 1,253 |
| 少于最低对话轮数的零产出 | 267 |
| 进入详细分析的实质性零产出 | 986 |

## 逐类归因

| 分类 | 数量 | 可以得出什么结论 |
|---|---:|---|
| 内容审查拒绝 | 0 | 有明确的终止状态; 不是普通空结果 |
| 源数据格式问题 | 5 | 日期、角色或空文本检查发现问题 |
| 数据 ID 冲突 | 0 | 同一公开 ID 实际对应不同聊天内容 |
| 完全相同输入出现不同结果 | 0 | 可以直接证明模型/批次结果不稳定 |
| 正确答案证据被漏提取 | 13 | 标注证明这里确实有应保留的信息; 原因未必是随机 |
| 相同文字、不同日期, 结果不同 | 175 | 日期也是模型输入, 因此只能算近重复, 不能证明随机 |
| 短会话, 可能没有长期信息 | 198 | 这是合理候选解释, 但不冒充已证明原因 |
| 仍无法确定, 或原聊天没有持久信息 | 862 | 保持未知, 不用猜测填补证据空白 |

## train150 中的批次位置现象 (观察性)

| 位置 | 零产出 / 会话 | 零产出率 |
|---|---:|---:|
| 前部 0-3 | 156 / 1,881 | 8.3% |
| 后部 4-14 | 830 / 4,428 | 18.7% |

后部风险约为前部的 **2.26 倍**。这能估计总体损失, 但不能据此把某一个会话标成随机失败。

## 随机批次实验 (因果证据)

| 检查 | 结果 |
|---|---|
| 同一聊天从批次前部移到后部 | 有记忆→空结果 8; 空结果→有记忆 0; McNemar p=0.0078 |
| 同一聊天平均记忆数 | 前部 4.5; 后部 1.6 |
| 批量 15 | 零产出 7/60 (11.7%); 平均 2.7 条记忆/会话 |
| 批量 5 | 零产出 5/60 (8.3%); 平均 4.8 条记忆/会话 |
| 批量 1 | 零产出 0/60 (0.0%); 平均 12.7 条记忆/会话 |

结论: 较大的提取批次会造成**位置相关的遗漏**, 这是受控实验支持的因果结论。
至于是输出长度、枚举漂移还是模型注意力分配导致, 现有证据不能继续细分。
